Pipeline

Extract, Transform, Load

O projeto aplica o padrão ETL com tarefas idempotentes e cargas incrementais via upsert pela chave primária dl_st_ref.

01

Extract

O DAG acctech_dl1 consulta as tabelas llx_facture e llx_societe no MySQL. O DAG acctech_dl2 lê os CSVs de faturas e clientes do Invoice Ninja.

02

Transform

Padroniza referências, converte datas, normaliza valores no formato brasileiro, mescla clientes e faturas e adiciona metadados de processamento com Pandas.

03

Load

Cria a tabela DH_INVOICES se necessário e faz upsert no PostgreSQL usando a referência da fatura como chave.

DL1

Dolibarr → PostgreSQL

Extração direta do banco transacional MySQL com filtro de faturas válidas e carga incremental.

MySQL PythonOperator Upsert
DL2

Invoice Ninja → PostgreSQL

Leitura dos arquivos CSV, enriquecimento com dados de clientes e normalização monetária pt-BR.

CSV Pandas merge Upsert

Sobre o projeto

Engenharia de dados aplicada ao negócio

Este projeto foi construído para transformar dados operacionais de CRM em informação confiável para tomada de decisão. O foco está em simplicidade operacional, idempotência e rastreabilidade.

  • Pipeline diário com retries e tarefas desacopladas
  • Modelo único para duas origens de CRM
  • Documentação e código versionados no GitHub
  • BI self-service com Metabase e SQL transparente
